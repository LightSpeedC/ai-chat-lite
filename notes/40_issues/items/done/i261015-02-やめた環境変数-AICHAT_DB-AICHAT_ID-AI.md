利用者の指示 (2026-10-15)。**この 3 つは、ソース (テストを含む)のどこにも残さない。名前を記録として残すのは、この課題だけにする。**

いま名前が残っているのはテストだけ (2026-10-15 時点)。`AICHAT_DB` はソースに 0 か所。`AICHAT_ID` ・ `AICHAT_URL` は、やめた変数が戻ってこないかを見張るテストに残っている。

- `tests/client-usage.test.mjs`: 使い方の表示に `AICHAT_ID` ・ `AICHAT_URL` が出ないことを確かめる 2 行と、そのコメント
- `tests/client-no-defaults.test.mjs`: 「`AICHAT_URL` のような変数は定義そのものが無い」のテスト

- [済] 上の 2 本のテストから、3 つの名前を消す。**見張りを消すか、名前を使わない形 (例: 使い方の表示に `AICHAT_` で始まる語が 1 つも出ない)に書き換えるかを決める**(2026-11-07、案 20-A: 名前を使わない形に書き換えた。`client-usage` は `/AICHAT_/` を見る 1 行に、`client-no-defaults` はテスト名を「`AICHAT_` で始まる環境変数を読む口が無い」に。全 40 本合格)
- [済] 消したあと、`text find` で 3 つの名前がソース (`src` ・ `tools` ・ `tests` ・ `deploy` ・ `bin`)に 0 件であることを確かめる (2026-11-07、Grep で 0 件)
- [済] 資料 (環境変数の調査資料の 3 章「やめた変数」・計画書・設計書など)に残る名前を、この課題へのリンクに置き換えるかを決める (2026-11-07、案 21-A: 当時の記録として残す。消すのはソースだけ)
