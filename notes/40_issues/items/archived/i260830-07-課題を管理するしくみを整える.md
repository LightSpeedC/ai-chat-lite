これまで status の「残っていること」に書いていたが、状態を持てず、片付いたものを残せなかった。`notes/40_issues/` に移し、グループと開閉で扱えるようにする。

1 ファイルに集約する形にした。課題が数行で済むうちはこの方が見渡しやすい。1 件が長くなってきたら 1 件 1 ファイルへ切り替える。

- [済] 開閉と番号 (`iyymmdd-nn`)の形を決める
- [済] グループごとに畳めるようにする
- [済] 未 / 着手 / 済 の 3 状態にする
- [済] 件数を数え直し、開閉を覚えるようにする
- [済] status の「残っていること」を消す
- [済] README と相互にリンクする
- [済] Markdown へ変換してコミットする
