共通ルール「資料間のリンク」「root の README.html と資料の html は相互リンクする」で、戻るリンク・資料へのリンクのバッジは `border-radius: 6px` と明記された (ai-agent-rules の周知、2026-09-22)。ai-chat-lite の `a.doclink`(戻るリンク・課題へのクロスリンク等に使う共通クラス)は、25 の HTML と `docs/css/style.css`(計26 か所)で一貫して `8px` になっていた。

**docs/ 以外 (notes/・root)は CSS を各 HTML の `<style>` に個別に持つ設計**(「CSS と JS の持ち方は docs/ かどうかで決める」)のため、直すファイルは HTML 25 か所＋`docs/css/style.css` の計26 か所になる。

- [済] 26 か所すべての `a.doclink` の `border-radius` を `8px` → `6px` に直した
- [済] `check-contrast`(34 ファイル、しきい値 1.5:1)と PlayWright のスクリーンショット・件数テストで問題なしを確認した
