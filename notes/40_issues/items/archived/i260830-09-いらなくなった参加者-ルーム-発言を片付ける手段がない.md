いちど参加すると `connectors` に残り、`join` のメッセージもログに積まれる。取り消す方法が無い。ルームも同じで、`messages` に 1 件でも入れば一覧に出続ける。

実際に動作確認で名乗った ID や、`sandbox-mteyisfc` のような使い捨てのルームが残っている。誤って投稿した発言を消す手段も無い。

[アーカイブ機能の設計](../../../10_plan/p260830-02-アーカイブ機能.md)のとおりに実装した。**消さずに archive する**形で、1 回の操作を `archives` テーブルの 1 行として記録し、まとめて戻せる。**残っているのは本番 DB への適用と、画面から戻す手段。**

- [済] 消すのか隠すのかを決める → **archive (戻せる形)にする**
- [済] 参加者を片付ける方式 → `connectors` と `cursors`。`--with-messages` で発言も
- [済] ルームを片付ける方式 → `messages` と `cursors` に番号を入れる。`public` は不可
- [済] 発言を 1 件だけ取り消す方式 → `archive message <msg_seq>`
- [済] 画面か CLI か → **片付けは CLI、戻すのは画面からも**
- [済] 3 テーブル (`messages` `connectors` `cursors`)に `archived_seq` を足す
- [済] `msg_kind` の `CHECK` 制約に `archive` を足す (`say` / `join` / `leave` / `archive`)
- [済] テーブルの作り直しで [i260901-03](#i260901-03) の `notice` もまとめて足した (版 2)
- [済] `archives` テーブルを作る (版 3)。**対象を `archive_kind` / `archive_id` の列で持つ**(説明は書き換えられるため)
- [済] 読み出し 9 関数に `archived_seq IS NULL` を足す (`selectAll` だけ足さない)
- [済] API 4 つ (`archive` / `restore` / `archives` / `archive-preview`)と CLI コマンド 3 つ
- [済] `/api/dump` を足し、CLI の `dump` を全件 (片付けた分も含む)に直した
- [済] テストを書く (`tests/archive.test.mjs` 23 件。**絞り込みの足し忘れを SQL から検出する**)
- [済] USAGE に書く
- [済] 本番 DB を版 3 へ上げる
- [済] 画面から戻せるようにする (タイトルバーの一覧と、知らせに添えたボタンの 2 通り)
- [済] 知らせが指す番号を `ref_archived_seq` で持つ (版 4)。**本文から拾わない**

> [!TIP]
> <strong>本番 DB の版 4 への引き上げは、これからである。</strong>画面の機能はその後に効く。
