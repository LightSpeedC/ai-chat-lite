<strong>接続先が環境変数のままである。</strong>テスト用サーバーを叩くには 2 つを渡すが、片方だけが環境変数になっている。

```powershell
$env:AICHAT_URL = 'http://localhost:'
node src\client\chat.mjs who --access-token <トークン>
```

[i260831-02](#i260831-02) で `AICHAT_ID` を引数にすると、**「ID は引数、接続先は環境変数」という不揃いが残る**。理由は同じ (コマンドラインを見れば分かる・シェルを問わない)。

### 向かう形

| 足すもの | 意味 |
|---|---|
| `--url` | 接続先をそのまま指定する。`AICHAT_URL` の置き換え |
| `--port` | <strong>`localhost` のポートだけを指定する。</strong>ふだんはこちらで足りる |

### 省略形

<strong>コマンドラインが長くなる。</strong>待受け 1 本で `--connector-id` `--access-token` `--room` `--port` `--wait-hour` が並ぶ。

| 短 | 長 | 備考 |
|---|---|---|
| `-c` | `--connector-id` | [i260831-02](#i260831-02) で足すもの |
| `-a` | `--access-token` |  |
| `-r` | `--room` |  |
| `-p` | `--port` |  |
| `-u` | `--url` |  |
| `-n` | `--n` | **すでにある**(`recent` の件数) |

> [!WARNING]
> **頭文字が衝突する。**`--room` と `--role` はどちらも `r`、`--to` と `--timeout` はどちらも `t`。大小で分けると (`-r` と `-R`)取り違える。
> **短い形を全部に付けない**のが素直である。よく打つものだけに付け、残りは長い形だけにする。

### いまの解釈の作り

`option()` は `--名前` だけを探す作りで、`-n` は `recent` の中で個別に見ている (`chat.mjs:233`)。**短い形を入れるなら、別名の表を持って 1 か所で解決する形に変える。**

### オプション名の一覧が 2 つあり、食い違っている

| 置き場 | 形 | 役目 |
|---|---|---|
| `chat.mjs` の `usage()` | `--help` で出る画面 | **実物。ここが正** |
| `USAGE-FOR-PROJECTS` | コマンド × オプションの表 | 他プロジェクト向けの一覧 |
| `notes/90_rules/test-server` | `--access-token` の例 | テスト用のみ |

<strong>放っておくとずれる。</strong>実際に `usage()` の `--retry-count` と `USAGE` の `--access-token` が抜けていた (不具合として先に埋めた)。**オプションを増やす前に、2 つを一致させる形を決める**(片方を生成するか、手で揃えるか)。

- [済] 計画を書く。[i260901-01](#i260901-01) と**同じ計画にまとめるか決める**
- [済] `--url` と `--port` を同時に指定したときの扱いを決める ([i260901-01](#i260901-01) の「両方はエラー」と揃えるか)
- [済] 短い形をどれに付けるか決める (衝突するものは付けない)
- [済] `AICHAT_URL` を廃止するか決める
- [済] `option()` を別名の表で解決する形に変える
- [済] `chat.mjs` の `usage()` を直す (**実物。ここが正**)
- [済] `USAGE-FOR-PROJECTS` の表と共通ルールを直す
