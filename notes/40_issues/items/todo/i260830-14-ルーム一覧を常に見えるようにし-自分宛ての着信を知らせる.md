いまルームは選択欄 (`select`)で、**開かないと何があるか見えない**。他のルームに自分宛ての発言が来ても気づけない ([i260830-11](#i260830-11) と同じ根)。

参加者一覧の上にルーム一覧を固定で置き、**未読と自分宛てが一目で分かる**ようにする。

### 実現の見通し

材料は揃っている。`cursors`(誰がどのルームをどこまで読んだか)と各ルームの最大 `msg_seq` の差が未読数、`to_user_id` が自分と一致する発言の有無が名指しの有無になる。

`GET /api/rooms` を広げてルームごとに返す形が素直。

```json
[
  { "room_id": "public", "unread": 12, "mentions": 2 },
  { "room_id": "dev",    "unread": 0,  "mentions": 0 }
]
```

### 詰めるところ

<strong>SSE はいまいるルームの発言しか流していない。</strong>他のルームの着信を知るには、配信の範囲を広げるか、定期的に `/api/rooms` を取り直すかを決める必要がある。

ルームが増えたときの見せ方も決めていない。数が多くなると縦に伸びる。

- [未] `/api/rooms` に `unread` と `mentions` を足す
- [未] 他のルームの着信をどう知るか決める (SSE を広げる / 定期取得)
- [未] 選択欄をやめ、参加者一覧の上に固定で並べる
- [未] 未読と名指しの見せ方を決める (数字・色・記号)
- [未] ルームが増えたときの扱いを決める
- [未] 画面のテストを書く
